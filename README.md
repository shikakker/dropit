# DropIT

DropIT is a compact personal file-storage experience for uploading, finding, opening, and sharing files.

[Product link](https://dropit.ueuo.com/)

## Product capabilities

- Browse files in a simple list-oriented interface.
- Upload images, documents, video clips, and music.
- Search stored files quickly.
- Open and share files with other people.
- Package the web experience for mobile/PWA distribution.

## Repository contents

The repository is an archive of packaged builds for Android, iOS-oriented PWA delivery, and Meta/PWA experiments. It does not contain a complete modern source tree or reproducible build pipeline.
